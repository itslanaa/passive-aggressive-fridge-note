A smart fridge leaves one dry, petty note for its owner on the door screen.

The program writes the note to `/output/entry.txt`:

> I've kept your salad cold for a week. You've opened me 40 times looking for something better. It's still salad.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/frn-out node main.ts
```
